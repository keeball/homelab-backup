Privacy Policy

Application: HomeLab Backup

Last updated: November 1, 2026

1. Purpose

HomeLab Backup is a privately operated backup solution used by its owner to store personal server backups in Google Drive.

2. Data access and use

The application uses rclone and the Google Drive API to upload, list and manage backup files in the owner's Google Drive account.

The application does not collect analytics, advertising data or personal information from other users.

3. File encryption and storage

Backup files are encrypted locally using rclone crypt before being uploaded to Google Drive. Encryption keys and passwords are managed by the owner.

4. Data sharing

No data is sold or shared with third parties. Google Drive is used solely as the owner's selected backup storage provider and is subject to Google's own privacy policy.

5. Data retention and deletion

Backup files are retained or deleted according to the owner's backup and retention settings. The owner can delete stored backups at any time.

6. Contact

This application is maintained for personal use. No public support or contact service is provided.
